## PROJECT OVERVIEW
This dataset contains raw and processed data from two experiments conducted on the same cohort of participants:
1. Position Adjustment Task (Spatial localisation)
2. MOT Task (Multiple Object Tracking)

## REPOSITORY STRUCTURE
The data is organised by participant in this way:
- P_XXX/ : Participant folder (where XXX is the Subject ID)
  - P_XXX_Exp_Position.csv : Raw trial data for the Position Adjustment Task.
  - P_XXX_Questionnaire.pdf : Gaming Habits Questionnaire.
  - MOT_Data/ : Subfolder containing Multiple Object Tracking data.
    - .mat : MATLAB data structures.
    - .txt : Raw trial logs.
    - .pdf : Summary plots for accuracy and staircase performance.


## MAIN DATA SUMMARY
The file "Data_Summary_Masterfile.xlsx" contains aggregated results for all participants.
